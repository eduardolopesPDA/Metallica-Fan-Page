# Exemplos — o mesmo formato, projetos diferentes

O formato "capítulos com identidade + uma história que conecta + confiança" funciona para assuntos bem diferentes. Abaixo, como a [spec modelo](SPEC-modelo.md) se preenche em seis casos. Só o primeiro foi construído; os outros mostram como adaptar.

---

## 1. Discografia de uma banda (homenagem) — projeto de referência

| Campo | Valor |
|---|---|
| Tipo | fan site não oficial, estudo de design |
| Recorte | Metallica, 1983–1991, cinco discos |
| Capítulos | um por disco: Cru, Eletricidade, Controle, Ruptura, Escuridão |
| Prólogo / epílogo | a formação da banda (1981–1983) / o show em Moscou e o legado |
| Blocos do capítulo | integrantes com instrumento ilustrado, faixas e créditos |
| Seções especiais | solo de baixo, teatro de marionetes com cordas, balança da justiça, mesa de som |
| Reações ao corte | rachadura, raio, cortina, martelo, pulso de luz |
| Mapa de rota | sim: a estrada de Los Angeles a Moscou |
| Conteúdo | pesquisa própria, 120+ páginas lidas, quatro status de fato |
| Direitos | só visual original; nenhuma capa, foto, letra ou logo |

## 2. Aniversário de uma empresa (freelance)

| Campo | Valor |
|---|---|
| Tipo | cliente, institucional |
| Recorte | os 30 anos da empresa |
| Capítulos | uma década ou uma fase cada: Garagem, Expansão, Virada, Escala |
| Prólogo / epílogo | o fundador antes da empresa / o presente e o que vem |
| Blocos do capítulo | números da fase, pessoas-chave, produtos lançados, depoimentos |
| Seções especiais | linha de produção interativa, mapa de filiais que acende, comparador antes/depois |
| Conteúdo | arquivo da empresa + entrevistas; o cliente aprova cada capítulo por escrito |
| Direitos | fotos e logos do cliente; origem de cada imagem registrada |
| Cuidados | dados financeiros só com aprovação; nomes de ex-funcionários com autorização |

## 3. Portfólio de projetos (pessoal ou estúdio)

| Campo | Valor |
|---|---|
| Tipo | pessoal |
| Recorte | seis projetos de 2020 a 2025 |
| Capítulos | um por projeto, cada um com o conceito que guiou o trabalho |
| História | o caminho profissional: o que cada projeto ensinou e levou ao próximo |
| Blocos do capítulo | problema, processo, resultado, números, depoimento do cliente |
| Voz | primeira pessoa |
| Direitos | imagens dos projetos com autorização dos clientes; NDA respeitado |

## 4. Lançamento de uma linha de produtos (campanha)

| Campo | Valor |
|---|---|
| Tipo | cliente, campanha |
| Estrutura | página única (estrutura B) |
| Capítulos | um por produto ou por momento de uso |
| História | o dia de uma pessoa usando os produtos, do amanhecer à noite |
| Conteúdo | textos aprovados pelo marketing; especificações técnicas do cliente |
| Cuidados | toda afirmação de desempenho com a fonte do teste; termos legais revisados |

## 5. Biografia ou memorial

| Campo | Valor |
|---|---|
| Tipo | homenagem ou cultural |
| Recorte | a vida de uma pessoa em fases |
| Capítulos | infância, formação, obra, legado (cada um com sua palavra) |
| Prólogo / epílogo | a origem da família / o que ficou |
| Conteúdo | documentos, entrevistas com família e colegas, imprensa da época |
| Cuidados | autorização da família; tom respeitoso nas cenas difíceis (use `still`) |

## 6. A história de uma cidade ou bairro (educacional)

| Campo | Valor |
|---|---|
| Tipo | educacional ou cultural |
| Capítulos | um por período histórico |
| Mapa de rota | sim: o mapa do lugar mudando a cada capítulo |
| Conteúdo | arquivo público, historiadores locais, jornais antigos |
| Blocos do capítulo | lugares, personagens, documentos, "como era / como é" |

---

## O que muda e o que fica

| Fica igual em todos | Muda conforme o projeto |
|---|---|
| Capítulos com um conceito de uma palavra | O que é um capítulo (disco, década, projeto, produto) |
| Filme com "anteriormente" e gancho | Voz da narração e tipo de ilustração |
| Status de cada informação | Origem do conteúdo e quem aprova |
| Som desligado por padrão, movimento reduzido | Direitos de imagem |
| Aprovação antes de cada commit e deploy | Rodadas de ajuste e prazos (freelance) |
